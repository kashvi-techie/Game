# Controls

- `W` or Up Arrow: throttle
- `S` or Down Arrow: brake
- `A` / `D` or Left / Right Arrow: steer
- `Space`: nitro
- `Shift`: handbrake
- `R`: reset the car to the track center, stop, and keep the current lap and race timers
- `Escape`: skip the intro, cancel the start countdown, pause a race, or resume a paused race
- `I`: skip the intro

Audio can be muted or adjusted with the on-screen volume control. The Web Audio graph initializes only after a user gesture.
